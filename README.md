## How to run the app

1. Initialize the project with the command **npm init -y**

2. Create a React app
   For example, _npx create-react-app my-app_
   or
   _npm create vite@latest my-app_

3. Install the library of custom components **npm i @polina_solodkova/custom-components-lib**

4. Import and use components
   For example, _import { Button, Checkbox, Switch } from '@polina_solodkova/custom-components-lib'_
